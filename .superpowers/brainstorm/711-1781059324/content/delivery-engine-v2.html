投放引擎 — 更新：从 FB 账户拉取模板

新增功能：导入 Facebook 广告账户已有的 Campaign/AdSet 配置为系统模板

模板来源（两种方式）

手动创建 在系统内新建模板，填写受众/预算/排期等参数（前面已设计的）
从 FB 导入 选择广告账户 → 拉取该账户下已有的 AdSet 列表 → 预览其配置（受众/预算/出价/版位） → 一键存为模板 → 可复用到其他账户

"从 FB 导入" 流程

导入流程

① 在模板管理页 → 点击"从 FB 导入"

② 选择一个已绑定的广告账户 → 系统调用 Meta API 拉取该账户下所有 AdSet

③ 展示列表：AdSet 名称 + Campaign 名称 + 受众摘要 + 日预算 + 出价策略 + 状态

④ 勾选想导入的 AdSet → 系统解析其完整配置（详细定位、排除条件、版位、转化事件）

⑤ 存为模板，可改名、可微调参数 → 之后其他账户也能用这个模板

拉取的数据字段

字段来源
受众定位targeting — 地区、年龄、性别、语言、详细定位、自定义受众、排除受众
版位targeting{device_platforms,publisher_platforms,facebook_positions,instagram_positions}
预算daily_budget / lifetime_budget
出价策略bid_strategy / billing_event / optimization_goal
转化事件promoted_object — pixel 事件、应用安装等
排期start_time / end_time
