投放引擎详细设计

半自动审核流程 + 全 Campaign/AdSet/Ad 管控

投放流水线（从素材到上线）

Pipeline

① 素材生成完成 → 历史记录中勾选 → "加入投放队列"

② 进入审核队列 → 预览素材+文案 → 确认/驳回 → 选择投放模板

③ 投放模板预设：受众包（地区/年龄/兴趣/语言） + 预算（日预算/总预算） + 排期（起止时间） + 出价策略（最低费用/费用上限/转化目标）

④ 批量提交 → 后台异步：上传创意到 FB → 创建 AdSet → 创建 Ad → 记录 ID 回写

⑤ 初始状态 PAUSED → 人工到 FB 检查 → 手动改 ACTIVE 或系统提供一键激活

投放模板

预设后可复用，减少每次投放的重复配置

模板字段说明
名称如 "欧美女性40+_兴趣小说_日预算$50"
受众位置（US/UK/CA/AU）、年龄（35-65+）、性别（女）、语言（英语）、详细定位（小说/电子书/阅读兴趣）、自定义受众排除
版位Facebook Feed / Instagram Feed / Audience Network（默认自动版位）
预算与排期日预算 / 总预算 + 起止日期（或长期投放）
优化目标转化量 / 链接点击量 / 落地页浏览（默认转化量）

Campaign 组织结构

每个 Campaign 按小说+账户区分，AdSet 按图片类型（scroll/lr_split等）分组，Ad 为单条素材

层级示例
Campaign: "霸总复仇_2024-06-10_act_12345" （小说名_日期_账户）
  AdSet: "scroll_欧美45+_日50" （图类型_受众细分_预算）
    Ad: "scroll_序章_第1章" （图类型_章节名）
    Ad: "scroll_第3章_冲突高潮"
  AdSet: "lr_split_欧美45+_日50"
    Ad: "lr_split_第2章"
