数据合并策略

ad_daily_stats 表扩展

现有唯一约束 UNIQUE(date, ad_account) → 扩展为 UNIQUE(date, ad_account, source)

新增列 source："pingykj" | "meta"

新增列 account_id：Meta 的实际 act_id（用于与 meta_accounts 表关联）

新增列指标：CTR, CPM, CPC, conversions, CPA（pingykj 行这些字段为 NULL）


同步策略说明
定时全量APScheduler 每 5 分钟同步一次（可配置），拉取近 90 天数据，按天+账户去重覆盖
增量更新记录 last_sync_date → 每次只拉取增量 → 避免全量重复
多账户并行ThreadPoolExecutor 并行拉取所有账户 → 单个账户失败不影响其他
速率控制每个 ad account 每秒 < 4 次 API 调用（Meta 标准限制），全局并发控制

账户映射（Meta ↔ pingykj）

如果同一个业务在两边都有账户（如 Meta act_12345 = pingykj adAccountId=67890），可能需要在 meta_accounts 表中手动建立映射关系，以便看板跨数据源做关联分析

选项描述
自动映射按账户名称模糊匹配 → 匹配不上的手动绑定
手动绑定在"账户配置"页面手动将 Meta 账户关联到 pingykj 账户 ID
不映射两个数据源在统一看板中分别显示，不做关联
