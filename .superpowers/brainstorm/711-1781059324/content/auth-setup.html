Facebook 认证与账户

Meta Marketing API 需要 OAuth 认证，这与现有 pingykj 的账号密码登录完全不同

Meta API 接入前提

Facebook App需要在 developers.facebook.com 创建应用，获取 App ID + App Secret
权限ads_management（创建/管理广告）+ ads_read（读取数据）
Access Token通过 OAuth 流程获取，分为短期(2小时)和长期(60天)两种
Ad Account每个广告账户有独立的 act_XXXXX ID，API 需指定账户操作
