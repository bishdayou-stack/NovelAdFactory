Facebook 开发者资源准备清单

接入 Meta Marketing API 需要在 Facebook 侧完成的准备工作

四步准备路线

1 注册 Facebook 开发者 10分钟
免费
前往 developers.facebook.com，用个人 Facebook 账号注册
2 创建应用 5分钟
免费
创建 → 选择 "其他" → 命名 → 获得 App ID + App Secret
3 生成 Access Token 10分钟
免费
Graph API 探索器 → 选择应用 → 获取 Token（ads_management + ads_read 权限）→ 置换为长期 Token（60天有效期）
4 确认广告账户 ID 1分钟
需已有
在广告管理工具 → 账户设置 → 找到 act_XXXXX 格式的账户 ID

拿到这些后，系统中需要配置

{
  "meta_app_id": "你的App ID",
  "meta_app_secret": "你的App Secret",
  "meta_access_token": "长期Token",
  "meta_ad_accounts": ["act_XXXXXXXX", "act_YYYYYYYY"]
}

现在的问题：投放管控粒度？

创建广告需要在 Facebook 上建 Campaign/AdSet/Ad 三级结构。你希望本系统掌控到什么程度？

A

全流程管控

在系统内创建 Campaign → AdSet → Ad，设置受众、预算、排期、出价策略。Facebook 广告管理器能做的，系统都能做。

B

只管理素材 + 发布

Campaign/AdSet 在 Facebook 手动建好，系统只负责上传素材、创建 Ad、关联到已有 AdSet。受众预算等不在系统内管。

C

折中：模板化投放

预设投放模板（受众包、预算区间、出价策略），创建时选模板+素材一键推送。不过度暴露复杂度但保留灵活性。
