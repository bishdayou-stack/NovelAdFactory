# Meta 管理中心重设计 — 设计文档

> 日期：2026-07-05 | 状态：待实现

## 目标

将 Meta 数据看板 + 账户配置合并为「Meta 管理中心」单页（`tab-meta`），左侧账户树 + 右侧数据面板，暗色专业风格。同时删除投放管理页面。

---

### 左侧面板交互

- 按 BM（`pingykj_account` 字段）分组树形展示
- 点击账户 → 右侧过滤到该账户
- 点击 BM 名称 → 显示该 BM 下所有账户汇总
- 「发现账户」按钮：弹出发现/导入面板
- 「API 配置」齿轮：弹出配置弹窗
- 底部显示已导入账户总数

### 右侧主区域

- 顶部工具栏：日期快捷键 + 对比基准下拉 + 手动同步按钮 + 同步状态
- KPI 行 → 趋势图+BM排行 → 异常+账户排行 → 日报明细

## 三、各模块详细设计

### 3.1 KPI 卡片行（6 个）

| 卡片 | 指标 | 对比 |
|------|------|------|
| 消耗 | SUM(spend) | vs 对比基准 |
| 转化 | SUM(purchases) | vs 对比基准 |
| ROI | revenue/spend | vs 对比基准 |
| CPA | spend/purchases | vs 对比基准 |
| 展示 | SUM(impressions) | vs 对比基准 |
| 点击 | SUM(clicks) | vs 对比基准 |

每个卡片底部显示对比箭头和百分比变化。

### 3.2 对比基准选择器

右上角下拉框，所有 KPI 和异常预警共用：

```
选项：
  - 昨天
  - 前天
  - 上周同期（7 天前当天）
  - 前 7 天均值
  - 前 30 天均值

默认：前 7 天均值
```

### 3.3 趋势图

- Chart.js 双 Y 轴：柱状图（消耗）+ 折线图（ROI）
- 暗色主题网格/坐标轴
- 右上角 7d / 30d 切换按钮
- Hover 显示详细数值

### 3.4 BM 汇总排行（新增）

按 `meta_accounts.pingykj_account`（BM 名称）聚合：

| 列 | 说明 |
|----|------|
| BM 名称 | pingykj_account |
| 账户数 | 该 BM 下 active 账户数 |
| 消耗 | SUM(spend) |
| 转化 | SUM(purchases) |
| ROI | SUM(revenue) / SUM(spend) |
| CPA | SUM(spend) / SUM(purchases) |

按消耗降序排列。

### 3.5 异常预警（新增）

对比当前周期 vs 对比基准（同上选择器）：

| 规则 | 等级 |
|------|------|
| 消耗下降 > 50% | 🔴 严重 |
| ROI 下降 > 30% | 🟡 警告 |
| CPA 翻倍 (>100%) | 🟠 注意 |

显示格式：`账户名 | 指标 | 当前值 | 对比值 | 变化% | 状态`

### 3.6 日报明细

保持现有结构，风格改为暗色表格：

| 列 |
|----|
| 日期 / 账户 / 消耗 / 转化 / ROI / CPA / 展示 / 点击 / CPM / CTR |

支持分页。

### 3.7 账户排行

| 列 |
|----|
| # / 账户名 / 消耗 / 转化 / ROI / CPA / 展示 |

按消耗降序，支持分页。

## 四、账户管理（左侧面板 + 弹窗）

### 4.1 左侧账户树

- 数据源：`GET /api/meta/accounts`（按当前用户过滤）
- 按 `pingykj_account` 字段分组，空值的显示为「未归类」
- 点击账户：右侧数据全部过滤到该 `act_id`
- 点击 BM 名：过滤到该 BM 下所有账户
- 搜索结果高亮

### 4.2 发现/导入面板

鼠标悬浮/点击「+发现账户」时展开：

```
┌──────────────────────────┐
│  Access Token: [______]  │
│  [发现账户]               │
│                          │
│  发现结果 (N):            │
│  ☑ act_123  账户A  BM:小明│
│  ☐ act_456  账户B  BM:小红│
│  [全选] [导入选中(N)]     │
└──────────────────────────┘
```

导入时自动传递 token，存入 `meta_accounts.access_token`

### 4.3 API 配置弹窗

点击齿轮图标弹出模态框：

```
App ID / App Secret / 默认 Token / API 版本
同步间隔 / 速率限制 / 代理地址
[保存]
```

安全：secret 和 token 不回显，留空则不修改

### 4.4 账户状态管理

账户行右键菜单或操作按钮：
- 切换 active/paused
- 删除账户
- 刷新 token

## 六、数据流

```
[左侧账户树] ← GET /api/meta/accounts
[发现面板]   → POST /api/meta/discover (用户 token)
             → POST /api/meta/accounts/import (带 token)
[KPI/图表]   ← GET /api/meta/summary
[趋势]       ← GET /api/meta/trend
[日报]       ← GET /api/meta/daily-stats
[排行榜]     ← GET /api/meta/account-ranking
[BM 汇总]    ← 新增 GET /api/meta/bm-summary（或前端聚合）
[异常预警]   ← 前端计算（比较当前周期 vs 对比基准）
[配置]       ← GET/POST /api/meta/config
```

### 新增后端 API

`GET /api/meta/bm-summary`：按 BM 聚合的汇总数据，参数与 summary 相同。

## 八、技术备注

- 前端单文件 `static/index.html`，所有新 UI 在 `<script>` 中构建
- Chart.js 已有 CDN 引入，趋势图复用现有 `metaChartTrend`，仅改主题色
- 左侧面板账户树：递归渲染 JavaScript 实现
- 异常预警：纯前端计算，对比当前周期 API 返回 vs 对比基准周期 API 返回
- BM 汇总：可从 `meta_account_ranking` 前端聚合，也加后端 API 备选
