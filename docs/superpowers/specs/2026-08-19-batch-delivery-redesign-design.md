# 批量投放流程重设计

日期：2026-08-19
状态：待审阅

## 背景

现有投放向导是「三步手动」：Step1 手动建系列 → Step2 手动加广告组 → Step3 手动分配素材，再发布。操作繁琐，且存在两个 bug：

1. 广告组/广告创建失败（根因：ABO 无预算、OFFSITE_CONVERSIONS 无 Pixel）
2. 系列 `fb_campaign_id` 未回写（已修复）

用户希望改成「批量复制」模式：选账户、填数量、选素材、三层各一套设置批量套用，一键生成 N1×N2×N3 个广告，每个广告只有素材不同。

## 核心数量模型

- 用户填三个数：系列数 N1、每系列广告组数 N2、每广告组广告数 N3
- 总广告数 = N1 × N2 × N3，且 == 素材总数（每广告一素材）
- 示例：1-1-10 → 10 广告；1-2-3 → 6 广告；10-1-1 → 10 广告

## 前端流程（投放向导重写为 4 步）

### Step 1 · 选账户 + 填数量
- 广告账户下拉（主页/数据集/受众按账户联动）
- 数量：系列数 N1、每系列广告组数 N2、每广告组广告数 N3
- 实时显示总广告数 N1×N2×N3

### Step 2 · 选素材
- 按总广告数选素材，恰好选满 N1×N2×N3 张（图/视频混合）
- 素材按选择顺序对应广告序号

### Step 3 · 三层设置 + 广告名
- **系列设置（一套）**：系列名前缀、目标（固定 OUTCOME_SALES）、预算策略（ABO/CBO）、主页、落地页
- **广告组设置（一套）**：广告组名前缀、组日预算（ABO 必填）、优化目标、数据集 Pixel（OFFSITE_CONVERSIONS 必填）、受众/定向、出价策略、归因窗口
- **广告设置（一套）**：广告文案（所有广告相同）、广告标题（用户填 5-10 个，每个广告随机选一个）、行动号召 CTA（下拉选择，所有广告统一）
- **广告名**：一个输入框填一个广告名字符串，所有广告都用这个名字（完全一样，不加序号）

### Step 4 · 预览 + 发布
- 预览：N1 系列 × N2 组 × N3 广告 = 总数，素材分配预览
- 「发布到 Meta」→ 批量创建，SSE 进度条

## 后端

### 新接口 `POST /api/delivery/batch-publish`
请求体：
- account_id
- 数量 N1/N2/N3
- 三层设置（系列/广告组/广告各一套 + 一个广告名，应用到所有广告）
- 素材列表（image_url + overlay_text，按顺序）

逻辑：
1. 校验 N1×N2×N3 == 素材数
2. 校验广告名非空、广告标题至少 1 个
3. 校验 Pixel 必填（OFFSITE_CONVERSIONS）
4. 批量落库：N1 系列、N1×N2 广告组、N1×N2×N3 素材队列
5. 后台投放：循环 N1 系列 → 每系列 N2 广告组 → 每广告组 N3 广告，全部 PAUSED
6. SSE 推送进度

### 投放循环
```
for i in 1..N1:
    create_campaign(系列设置, 名 = 前缀-i)
    for j in 1..N2:
        create_adset(广告组设置, 名 = 前缀-i-j)
        for k in 1..N3:
            idx = (i-1)*N2*N3 + (j-1)*N3 + (k-1)
            create_ad(素材[idx], 广告名, 广告文案, headline=标题[随机], cta=CTA)  # 标题随机，其余同名
```

注：`meta_api.create_ad` 需扩展 `headline` 参数（写入 `creative.object_story_spec.link_data.name`），并保留 `call_to_action`（CTA）。

## 数据模型

复用现有表，不新增：
- `delivery_campaigns`：N1 条（各系列设置相同，名加序号）
- `delivery_adsets`：N1×N2 条
- `delivery_queue`：N1×N2×N3 条（每广告一素材，含广告名）

## 命名规则

- 系列：`{系列前缀}-{i}`
- 广告组：`{广告组前缀}-{i}-{j}`
- 广告：所有广告用同一个名字（用户填的一段字）

## 校验规则

- N1、N2、N3 均 ≥ 1
- N1×N2×N3 == 素材数
- ABO 模式：组日预算 > 0
- OFFSITE_CONVERSIONS：Pixel 必选
- 广告名非空（一个名字应用到所有广告）

## 顺带修复

- 系列 `fb_campaign_id` 回写（已做）
- ABO 无预算、OFFSITE_CONVERSIONS 无 Pixel 的报错（前端 + 后端校验）
